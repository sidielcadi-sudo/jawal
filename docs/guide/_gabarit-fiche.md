# Gabarit d'une fiche de procédure

> Modèle à recopier pour toute nouvelle procédure. Les six rubriques sont
> **obligatoires** : c'est ce qui distingue un manuel de procédure d'une visite
> guidée de l'interface.

---

## N.N Titre de la procédure, à l'infinitif

> Exemple : « 1.4 Inscrire un nouvel élève »

**Qui** — rôles autorisés, avec le libellé métier.
*Ex. : Scolarité, Secrétariat, Administrateur établissement.*

**Quand** — le déclencheur, dans la vie de l'établissement.
*Ex. : à réception du dossier d'admission complet, avant l'affectation en classe.*

**Prérequis** — ce qui doit exister avant de commencer.
*Ex. : l'année scolaire est ouverte (§ 9.1) ; la classe cible est créée (§ 9.3) ;
la grille tarifaire de l'année est publiée (§ 4.1).*

**Étapes**

1. Dans le menu de gauche, cliquer sur **Inscriptions**.
2. En haut à droite, cliquer sur **Nouvelle inscription**.
3. Renseigner l'onglet **Identité**… *(un geste par étape, jamais deux)*
4. Cliquer sur **Enregistrer**.

**Résultat attendu** — ce que l'utilisateur doit voir pour savoir que c'est fait.
*Ex. : l'élève apparaît dans la liste avec le statut « Inscrit » et un
échéancier a été généré, consultable depuis sa fiche, onglet Finances.*

## Conventions typographiques

| Élément | Mise en forme | Exemple |
|---|---|---|
| Libellé de bouton, de menu, d'onglet | **gras** | cliquer sur **Enregistrer** |
| Chemin de navigation | gras + flèches | **Paramétrage → Utilisateurs** |
| Valeur à saisir | « guillemets » | saisir « demo » |
| Renvoi interne | § numéro | voir § 2.3 |
| Avertissement | bloc `> ⚠️` | > ⚠️ Action irréversible. |
| Astuce | bloc `> 💡` | > 💡 Le raccourci … |
